Taruh 5 file font di folder ini dengan NAMA PERSIS seperti berikut:

  cormorant-garamond-regular.ttf   (Google Fonts: Cormorant Garamond -> static -> Regular)
  dawning-of-a-new-day-regular.ttf (Google Fonts: Dawning of a New Day -> Regular)
  tangerine-regular.ttf            (Google Fonts: Tangerine -> Regular)
  inter-regular.ttf                (Google Fonts: Inter -> static -> Regular)
  inter-medium.ttf                 (Google Fonts: Inter -> static -> Medium)

Cara: buka fonts.google.com, cari nama fontnya, klik "Get font" -> "Download all",
ekstrak zip-nya, salin file yang sesuai ke sini, lalu ganti namanya.
Setelah itu jalankan ulang: npm run dev  (atau npm run build)
